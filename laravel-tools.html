CONCEPT 01 / 085 MIN READ

THE TOOLKIT

Laravel and its tools

Laravel gives a PHP web application a sensible structure and tools for common jobs. You focus on what makes your application useful.

01 / WHY A FRAMEWORK

A framework gives you a starting structure.

Without a framework

You would have to decide how to handle every request, connect to the database and organise the project.

With Laravel

Routing, database access, templates, validation and testing fit into established patterns.

THE MAIN IDEALaravel is built with PHP.

Laravel is a PHP framework, not a replacement for PHP. You still write PHP code, but within a consistent structure.

02 / THE TOOLS

Different tools do different jobs.

Composer

Installs and manages PHP packages, including Laravel itself.

Artisan

Laravel’s command-line helper for generating files, running migrations and tests.

Tinker

A small interactive console for trying PHP and Eloquent expressions.

Blade

A template language for combining HTML with data from Laravel.

Breeze

Starter code for registration, login and account management.

Docker

Runs the project’s development services in a predictable environment.

Terminal
composer install
php artisan route:list
php artisan tinker

Run Artisan commands in the Laravel project directory, inside the appropriate development container.

resources/views/books/index.blade.php
<h1>Books</h1>
<p>{{ $book->title }}</p>

Blade escapes output between {{ and }} by default.

If {{ }} or @foreach looks unfamiliar, see the Blade templates concept page for a gentle introduction.

03 / CHECK YOUR UNDERSTANDING

Which tool would you use?

?Which tool do you use to run Laravel commands from the terminal?Reveal answer

Artisan. For example, php artisan route:list shows your routes.

?Which tool adds PHP packages to your project: Composer or Blade?Reveal answer

Composer installs packages. Blade is used to build page templates.
