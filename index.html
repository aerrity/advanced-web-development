01 / THE PURPOSE

From web pages to
web applications.

Earlier in Creative Computing, you've worked with programming, websites and databases. This module brings those skills together. Instead of building individual pages, you'll create an application where users can sign in, work with data and interact with information stored in a database.

You'll learn the structure of a server-side web framework and why developers use one: it helps organise code, manage common tasks and build more reliable software.

The aim isn't just to make something work. It's to understand how a request travels through your application, how to test what you've built, and how to make decisions you can explain. Those are skills you'll continue to use in software projects throughout the degree.

02 / WHAT YOU'LL PRACTISE

Learn by building.

Work through a complete example, then apply those ideas to a project of your own.

01

Understand the framework

See how routes, controllers, Blade views and models work together to handle a web request.

02

Work with data

Design tables and relationships, use migrations and Eloquent, and prepare realistic sample data.

03

Build real features

Create forms, validate input, handle authentication, manage permissions and make information searchable.

04

Test and explain

Use automated tests and Git, then demonstrate and explain how your application works.
