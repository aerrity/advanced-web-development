CONCEPT 03 / 086 MIN READ

HTML + A LITTLE LOGIC

Blade templates, explained

Blade files look like HTML, but contain unfamiliar symbols such as {{ }}, @if and @foreach. They are simply Laravel’s way of putting information and small decisions into a page.

01 / FIRST, THE IDEA

HTML is still the foundation.

A Blade template is a file ending in .blade.php, usually inside resources/views. Laravel processes the Blade instructions on the server and sends ordinary HTML to the browser.

Controller

Gets the data and passes it to the view.

Blade view

Displays the data and chooses which HTML to show.

BookController.php · pass data to a view
public function show(Book $book)
{
    return view('books.show', compact('book'));
}

The view now has a $book variable available.

books/show.blade.php · display the title
<h1>{{ $book->title }}</h1>

{{ }} means “display this value”. Blade escapes special HTML characters by default, helping prevent unsafe HTML from being injected.

THE MAIN IDEABlade is not another programming language you need to learn from scratch.

It is mostly HTML, with small Laravel instructions mixed in.

02 / LEARN THE SYMBOLS

Four patterns you will see repeatedly.

Blade · display a variable
<p>{{ $book->title }}</p>

Print the title of the book.

Blade · show something only when a condition is true
@if ($book->cover_image)
    <img src="{{ $book->cover_image }}" alt="Book cover">
@else
    <p>No cover available</p>
@endif

@if checks a condition. @else provides a fallback. @endif ends the block.

Blade · repeat HTML for each record
@foreach ($books as $book)
    <li>{{ $book->title }}</li>
@endforeach

@foreach repeats the list item for every book. The singular $book represents the current item.

Blade · handle an empty list
@forelse ($books as $book)
    <p>{{ $book->title }}</p>
@empty
    <p>No books yet.</p>
@endforelse

@forelse works like a loop, but also handles an empty collection.

03 / REUSING PAGE PIECES

Components, includes and forms.

Blade · reuse a template fragment
@include('books.partials.card', ['book' => $book])

This inserts resources/views/books/partials/card.blade.php and passes it the selected book.

Blade · Breeze layout and form directives
<x-app-layout>
    <h1>Edit {{ $book->title }}</h1>
    <form method="POST" action="{{ route('books.update', $book) }}">
        @csrf
        @method('PUT')
        <input name="title" value="{{ old('title', $book->title) }}">
        <button>Save</button>
    </form>
</x-app-layout>

The <x-app-layout> component supplies a shared layout. route() builds a URL, @csrf adds a security token, @method specifies the intended method, and old() can restore submitted form values.

A Blade file may mix plain HTML, components and directives. Read the plain HTML first, then work out what each Blade expression adds.

04 / CHECK YOUR UNDERSTANDING

Read a template one line at a time.

?What does {{ $book->title }} do?Reveal answer

It displays the book’s title as escaped text in the HTML sent to the browser.

?Which directive would you use to display one card for every book?Reveal answer

@foreach (or @forelse if you also want an empty-list message).

?Does the browser receive the literal @if and @foreach text?Reveal answer

No. Laravel processes those instructions on the server and sends the resulting HTML to the browser.
