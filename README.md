# Advanced Web Development · module site and concept notes

Open `index.html` to browse the module homepage. Open `theory.html` to browse nine concept notes. The whole site is static and can be hosted on GitHub Pages.

## Contents
- `index.html`: module landing page, resources, assessment, official learning outcomes.
- `theory.html`: concept notes index.
- Seven topic HTML pages, each with small Book Reviews examples, visual explanations, self-checks and links into the Learning Lab.
- `concepts.css` and `concepts.js`: concept-page styles and copy-code controls.
- `learning-lab/`: unchanged v17 practical learning site, bundled for local links.
- `resources/assignment-brief-2026.pdf`: supplied assignment brief.

The notes are conceptual, not a substitute for the guided build. Short illustrative snippets intentionally omit unrelated imports/configuration; they are explained in context, not meant to be copied as complete classes.
