Putting it all together

The most useful mental model is a complete journey. Follow an edit request and explain why each part of your application is involved.

Your exact request may pass through different middleware and authorisation rules. Check your own routes and controller code.

02 / FIND EACH STEP

Here is a simplified example.

routes/web.php
Route::resource('books', BookController::class);
BookController.php · update() (simplified)
public function update(Request $request, Book $book)
{
    $data = $request->validate([
        'title' => ['required', 'string'],
    ]);

    $book->update($data);
    return redirect()->route('books.show', $book);
}

The real controller may handle authors, cover images and permissions too.

Terminal · inspect your app

Open each file as you work through the request. Check that every step connects to the next.
