# Instructor notes

This directory contains source-code verification details for the teaching edition. These files are not needed by students to use the learning site.

- `VERIFICATION.md`: validation performed and important limitations.
- `verification.json`: counts and recorded results for the source checks.

The student-facing lesson interface deliberately avoids showing provenance labels for each code fragment. Some teaching snippets show earlier stages of the project; the optional **View completed implementation** sections show the finished project, which may include features from later steps.
