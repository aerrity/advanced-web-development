# Independent advanced extensions (v15)

This release adds 12 challenge-based activities in four optional and independent modules: E1 Reading lists, E2 Ratings and recommendations, E3 Administration and permissions, E4 Interactive search.

Every extension assumes completion of the core Module 08 application. Extensions are not part of the original GitHub solution and are not worked solutions. Students implement and test them independently. Each challenge contains a brief, technical guidance, implementation milestones, evidence criteria, and a stretch goal.

The core 35 lesson objects are preserved. Their localStorage key and schema remain unchanged. Completion counts are separated: core remains out of 35, extensions out of 12. Progress import/export supports extension IDs using the existing schema. Independent extension navigation never jumps into another extension.

Suggested assessment: demonstration of behaviour and test coverage, rationale for design choices, and a short reflection on bugs identified.
